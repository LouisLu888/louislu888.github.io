Swyx 试用一周，把 QA、视频剪辑等五类活交给 Agent

Swyx 说他试用 Devin Bots 一周，交出了 AEO、QA、跨平台移植、个人事务和视频剪辑；新模型 Astra 跑着他们大部分内容发布流程，他称公司在自筹资金下人均收入超过 100 万美元。

谁·场景
Swyx，Latent Space 播客和 AI Engineer 大会的主理人，同时与 Cognition（Devin 的公司）有关联。
怎么用
用常驻的 Devin Bots 认领整块结果而不是单个任务，由它管理子 Agent、自查，并用交互式页面汇报进度，代替长对话；内容发布流水线主要交给 GPT-6.2 Astra。
结果
他说一周内交出五类工作，同时从本地 worktree 转到云端运行；他还说没有 Astra，公司达不到人均超过 100 万美元的收入效率。
你可以试
挑一个你负责的问题域（比如某产品的回归测试），写清楚「什么算完成」和汇报格式，让 Agent 对结果负责一周，再看你还要介入多少。
注意
同一个模型评价两极：Matt Shumer 测了几周，说 Astra「基本不可用」，他的其他 Agent 退回了大量 Astra 子任务产出；也有人认为问题出在运行框架上。

Swyx 在 X 帖子里说，他试用 Devin Bots 一周，交出了 AEO、QA、跨平台 App 移植、个人事务自动化和视频剪辑。他的结论是：别期待「AI 员工」，我们还没有 AGI，期望过高只会失败。他觉得眼下该要的，是比单个任务高一层的东西：能对结果负责的 Agent 管理者。他说用人也按这个标准：能认领一块问题、主动带着方案回来的人，他更看重。

另一条帖子里，他说新发布的 GPT-6.2 Astra 是他用过最好的流程自动化模型，不再陷入死循环，能通过压缩上下文和写技能来学习，现在跑着 Latent Space 和 AI Engineer 的大部分内容发布流程。

反方意见同样强烈。Latent Space 当日简报整理了评价：Matt Shumer 认为 Astra 基本不可用，Pietro Schirano 认为早期问题多半出在运行框架上。换模型之前，拿自己的真实流程跑一遍再下结论，比看测评可靠。
