把父亲的文件柜搬进 Claude Code：一个家庭的共享大脑

数学教师 Scott Farrar 用 Claude Code 加 Obsidian 管家务：拍下每台家电，整理成型号、序列号和保修清单，再用它比较保险报价、维护全家的待办总表。

谁·场景
数学教育者、家长 Scott Farrar，和妻子一起管理家务，在 How I AI 节目里演示。
怎么用
他把零散的原始信息丢给 Claude，由 Claude 维护 Obsidian 里的 Markdown 文件；用一个自定义 linter 防止待办等文档越写越长；墙上的显示屏展示行程和待办。
结果
他说家电照片变成了可搜索的保修档案；Claude 能结合房屋细节比较保险报价，指出可能的保障缺口，并拟好追问的问题。
你可以试
先让 AI 告诉你它需要哪些背景，比如给每台家电拍照，从一个 Markdown 文件夹做起。
注意
Claude 建议用 GitHub 避免文件冲突，但妻子觉得太复杂。最后共享脚本放 GitHub，日常文件放 Dropbox。agent 跑偏时，他会先查清楚，防止错误信息写进记忆文件。

Scott Farrar 在节目里说，他不再依赖长对话，原因是聊天的问题在于记忆漂移，而不在于模型不够聪明。Claude Code 把上下文存在 Markdown 文件里，他能打开检查、修改，下次会话接着用。他问 Claude 该怎么记录这个家，Claude 建议给每台家电拍照，这些照片后来成了带型号、序列号和保修信息的清单。

他和妻子把能想到的家务都写下来，Claude 按优先级、费用和相关资料整理成一张总表，逾期的事会被提出来。墙上的显示屏展示近期出行、未完成任务、最近完成的事和每日小建议，全家人都看得到。比较保险时，Claude 用房屋的详细资料逐项对照，他不用全听推销员的。

交给 AI 的主要是家电、房屋和保单信息，文件都在本地，自己看得见。想照着做，可以从一个场景起步，比如家电保修。输入随便写，整理交给 AI，文件由自己审核。
