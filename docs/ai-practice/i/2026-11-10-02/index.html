AI App·本周演示·2026-11-09·US

agent 配齐数据和权限后，一条 UGC 广告约 5 美元

Cody Schneider 演示用 agent 做投放：输入品牌网址出五条静态广告。他说一条带动效的 AI 虚拟人广告约 5 美元，请人做要 300 到 500 美元。

谁·场景
营销数据平台 Graphed 创始人 Cody Schneider，在 Greg Isenberg 的节目里给产品没人买的创始人现场演示。
怎么用
Airbyte 把广告、分析、CRM、支付数据同步进 ClickHouse 仓库，agent 只从仓库读数据。Facebook 和 Google Ads 的 API 只用来写，比如上传素材、关停广告。再给 agent 接上生图、视频、线索类 API。
结果
静态广告 skill 读品牌网址，提取品牌风格，查对手广告库，再从 Reddit 等处找痛点，提出五个方案并生成成图。他说 Google Ads agent 能在 20 秒内审完 5000 个搜索词，判断搜索意图是否匹配落地页。
你可以试
先只做一步：把产品网址交给 agent，让它整理用户痛点、写五条广告文案，人工挑一两条，小预算投放测试。
注意
读写分开，是为了防止 agent 高频请求违反平台 API 条款、导致封号。Greg 补充说，还需要大量参考素材和一个给广告打分的创意总监 agent，上线前保留人工把关。

这期节目里，Cody Schneider 用自家平台演示，同时讲了开源组件的拼法。他把 agent 的工作环境分成三块：数据、平台写权限、工具。数据全放进仓库有两个好处：agent 可以随便查，不撞 API 限流；广告还能一路关联到付款和客户终身价值，看出哪类素材带来的客户更值钱。

现场他给 Idea Browser 生成了五个方向，比如「别再花六个月做一个没人要的点子」，再把同一组概念改写成虚拟人口播视频脚本。他的判断是，Facebook 的算法会把好素材匹配给合适的买家，出素材的速度最重要。

对独立开发者来说，最低成本的版本是只用静态广告这一步做需求验证。全套数据管道要接很多付费服务，等投放确实有效再补也来得及。
