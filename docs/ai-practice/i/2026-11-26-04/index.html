Karpathy 让 Claude 跑 7 小时，把 31 个公开数据源做成文明式地图

Andrej Karpathy 用 Claude Code 让模型下载并解析 31 个美国公开数据源，7 小时、4.5 万行代码后，做出一张可浏览的文明风格地图。

谁·场景
AI 研究者 Andrej Karpathy，周末式的个人探索项目。
怎么用
在 Claude Code 桌面版里使用 Opus 5.5（medium 档）并打开 ultracode，让它自己下载 Census、BLS、NOAA 等数据，统一映射到 25 公里的六边形网格上。
结果
他说跑了 7 小时，生成约 4.5 万行代码，覆盖 3100 多个县和 524 个都市区，有 19 种视图，并已部署上线。
你可以试
手头有多个公开数据源时，可以先给 agent 一个明确的统一口径（比如同一网格、同一套指标），让它负责下载、清洗和对齐。
注意
这次用掉了他半周的 Claude 额度；Claude 自作主张跳过了几个州和领地，结果需要人工核对覆盖范围。

Karpathy 在 X 上介绍了这个项目：海拔、GDP、就业、电厂、港口、灾害等数据全部换成游戏语言。GDP 对应金币产出，城市的区划对应真实的产业专长，比如 San Jose 是 Campus，并标注当地每 4 个劳动者里就有 1 个是工程师、程序员或科学家，全国平均是 1/14。Explorer 可以把任一县的任一列转成表格和散点图，并和地图联动。

值得借鉴的是任务的设定：目标模糊（他自己也说不清要做成什么），但数据口径和呈现规则写得很具体，比如奇观按国家公园访客量、大学研发经费这类公开规则来选。长时间运行的 agent 适合这种需要大量下载、解析和对齐的数据工作。最后仍要人检查覆盖范围有没有缺漏。
