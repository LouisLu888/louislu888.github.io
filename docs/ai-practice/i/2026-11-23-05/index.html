一句提示词，做出各浏览器对照的下拉框样式页

Simon Willison 让 Claude 生成一个页面，列出 select 下拉框的各种样式，在多个浏览器截图比较后，定下了自己的一套 CSS。

谁·场景
开发者 Simon Willison 不满意 HTML 下拉框在各浏览器里长得不一样，在 Chrome 里尤其难看。
怎么用
他给 Claude Fable 5.2 的提示词是：做一个 HTML 页面，展示 select 框所有的样式写法，他打算在每个桌面和移动浏览器里截图。
结果
试过一轮后，他选定了 appearance: none 加内嵌 SVG 箭头、6px 圆角、浅灰边框的写法，并贴出了三个浏览器里的效果。
你可以试
遇到「哪种写法最好」这类设计选择时，先让 AI 把所有选项并排做成一页样本，再自己在真实环境里对比挑选。
注意
AI 负责把选项铺开，判断仍要自己在每个目标浏览器里看过才能做。

这是一个很小的例子（本人记录）。他要 AI 交出的不是答案，而是一张可以拿来比较的样本页，提示词里还写明了用途：要在各个浏览器里截图。最后用哪套样式，由他看完截图后自己决定。

这个方法可以用到很多岗位：设计师比较组件样式，PM 比较几种文案或页面布局，运营比较邮件模板。先说清「我要拿它做什么对比」，AI 生成的样本才会覆盖到你真正需要的维度。
