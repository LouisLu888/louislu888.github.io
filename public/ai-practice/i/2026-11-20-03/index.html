Linear 一半工单由 Agent 创建，AI 功能怎么定价

Linear COO Cristina Cordova 说，一年前 Agent 创建的工作占 3%，现在超过一半；客服回复由 AI 起草、人来决定，编码会话按 API 原价加少量加价收费。

谁·场景
Cristina Cordova 是 Linear 的 COO，之前在 Stripe 待了七年半。她在 Latent Space 节目里讲了 Linear 年度经常性收入（ARR）过 1 亿美元途中做的取舍。
怎么用
Linear 推出了 MCP server 和 Agent 平台。客服不让 LLM 自己回工单，由 AI 起草、人决定发什么。编码会话让用户自选 OpenAI 或 Anthropic 的模型，按公开 API 价格加少量加价收费。
结果
公司称有 4 万多付费客户，净收入留存 177%。她说三年半来没有一起因为客服体验差引起的投诉升级。客户还常以为回复是 AI 写的，因为回得太快。
你可以试
给自己的产品同时盯两条线：Agent 调用量和用户打开 App 的次数。新的 AI 功能先作为免费 beta 上线，同时提前告知以后会收费。
注意
按 API 原价加价收费的前提是客户愿意自己选模型；按效果收费在 Linear 也还没找到办法。

Latent Space 这期访谈里，Cordova 说 Linear 2025 年 5 月上线 MCP server，现在超过一半的 issue 由 Agent 创建。她的判断是，满足于当"一个挂着 MCP 的数据库"的 SaaS 是在犯大错。她同时看 Agent 用量和 App 用量两条线：Agent 用量涨而 App 用量不涨，说明你正在变成可替换的商品。

定价上，她的原则是对产生成本的部分收费，其余免费。座位费保留；Linear Agent 的聊天功能用的是前沿模型，仍然免费；编码会话和定时任务 Loops 走 AI 额度。新的 AI 功能先作为免费 beta 上线并提前告知会收费，价格从高往低调，不把原来免费的东西改成收费。

她还提醒，现在很多企业有专门的 AI 预算，采购变快了，但买家签的多是一年期合同和付费试点。等这些合同到期续约时，才能看出谁的 ARR 是真的。做小型 SaaS 的人可以照搬两件事：客服用 AI 起草、人工把关；把模型成本透明地传给客户，再加一层服务费。
