CTO 让 Mac Mini 上的 agent 替他审批、催回复、订餐

Innovaccer CTO Ankit Maheshwari 用 OpenClaw 搭了个人助手 Jarvis，从工作审批一路扩展到打电话催人、订餐厅和智能家居，每月 Anthropic 账单 500 到 600 美元。

谁·场景
医疗科技公司 Innovaccer 的 CTO Ankit Maheshwari，在 Claire Vo 的 How I AI 节目里演示他放在一台 Mac Mini 上运行的 OpenClaw 助手。
怎么用
起点是那些让他成了瓶颈的审批，比如 Navan 里的差旅审批。他用 soul file 给每个子 agent 定角色，健康教练、邮件分拣各自独立，再加一个主 soul 统筹。语音外呼也拆成单独的子 agent，Slack 上没回复的同事由它直接打电话。
结果
同一套系统后来接手了点午餐、和餐厅谈订位、到家前开空调。他说过去一个全局 agent 扮演多个角色时会出现幻觉，拆成职责明确的子 agent 后才稳定下来。
你可以试
挑一件你每天都要点一下、却总在拖延的小事（审批、提醒），先只给 agent 这一个权限，跑通后再加下一件。
注意
他每月在 Anthropic 上花 500 到 600 美元，正在测试 GLM 5.3 Flash 这类便宜模型能接手多少。给 agent 打电话、下单的权限，需要事先设好护栏。

这期节目的主题是他的「1% 烦恼法则」：每件只占用一点注意力的小麻烦都值得自动化。第一个自动化处理的是审批。他提到审批通知容易被漏掉，一单卡住，后面的人跟着等。

结构上可以借鉴两点。第一，用职责单一的子 agent 代替一个什么都管的 agent：他遇到过全局 agent 混淆角色、编造内容的问题，拆开之后才可靠。第二，像带新员工一样和 agent 说话，交代背景和期望，不追求写复杂指令。节目里还讲了一次他在飞机上时护栏被考验的经历，24:12 起专门讨论护栏。

适合尝试的人：手头有大量审批、协调类小事，愿意把日历、Slack、外卖、出行这些账户的权限交给 agent。外呼部分用到了 Bland AI、ElevenLabs、Twilio 这类语音和电话服务。25:49 起讨论能否用本地模型降低成本，以及 GLM 5.3 Flash 能做和做不了的事。
