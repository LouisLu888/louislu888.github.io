一条命令，用本地模型跑起数据库 Agent

Simon Willison 发布 datasette-llm 0.1a11，新增 OpenAI 兼容接口支持，一条 uvx 命令就能用 LM Studio 上的本地模型驱动 Datasette Agent。

谁·场景
开发者 Simon Willison 维护 Datasette，一个开源的数据探索工具，这次更新的是其中配置 LLM 的插件。
怎么用
新版本支持任何兼容 OpenAI 协议的接口。他演示的做法是：下载示例数据库 content.db，用 uvx 加载 datasette-agent，把默认模型指向 LM Studio 的本地地址 localhost:1234/v1，模型选 qwen3.8-27b。
结果
本机会启动一个 Datasette Agent 服务，由本地模型驱动，不需要调用云端 API。Ollama 和 llama.cpp 同样可以接入。
你可以试
装好 LM Studio 或 Ollama 并加载一个模型，照着他文章里的命令先用示例库跑通，再换成自己的 SQLite 文件。
注意
插件还是 alpha 版本。Agent 好不好用，取决于你的机器能跑多大的模型。

Simon Willison 在发布说明里给了完整命令：用 uvx 带上 datasette-agent 启动 Datasette，通过 -s 参数把 datasette-llm 的默认模型设成 LM Studio 上的 qwen 模型，接口地址填本地端口。启动后，就能在浏览器里用本地模型驱动的 Agent 操作数据库。

这对手里有敏感数据、不方便上传到云端的分析师和运营有用。客户名单、内部报表可以导成 SQLite，留在自己电脑上让 Agent 查询和整理。先用他提供的示例库跑通，确认模型能正确理解表结构，再接真实数据。查询结果要和原始数据抽样核对。

原文：Simon Willison
